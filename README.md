# LemonCANDY42/tap

Homebrew formulae for [compactlab](https://github.com/LemonCANDY42/compactlab), which recommends auto-compact
thresholds for coding agents from your own session logs.

```bash
brew install LemonCANDY42/tap/compactlab
```

Python 3.13 from Homebrew; no other dependencies. Upgrade with `brew upgrade compactlab`.
