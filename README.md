# LemonCANDY42/tap

Homebrew formula and cask for [compactlab](https://github.com/LemonCANDY42/compactlab), which recommends auto-compact
thresholds for coding agents from your own session logs.

```bash
brew install LemonCANDY42/tap/compactlab
```

Python 3.13 from Homebrew; no other dependencies. Upgrade with `brew upgrade compactlab`.

The menu bar app (macOS 14+, signed and notarized) installs the engine with it:

```bash
brew install --cask LemonCANDY42/tap/compactlab-app
```
